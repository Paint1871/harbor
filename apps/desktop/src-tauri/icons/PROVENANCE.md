# Window icon provenance

`icon.png` is an original Harbor mark rasterized by `render.py` in this
directory. Geometry follows the product mark: a dark field (`#0B0B0C`), an open
ring (harbor mouth) in `#F5F5F5`, and an inner beacon in `#22D3EE`.

It was not traced, sampled, or derived from another product's assets. There is
no external prompt or seed; the rasterizer is the source.
